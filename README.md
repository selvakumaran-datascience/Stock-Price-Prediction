# 📌 Project Overview

This project is an **AI-powered Stock Price Prediction System** that analyzes historical stock market data, performs advanced feature engineering, visualizes market trends, and predicts the **next day's closing stock price** using Machine Learning.

The project follows a complete Data Science workflow:

- 📊 Data Collection
- 🧹 Data Cleaning
- 📈 Exploratory Data Analysis (EDA)
- ⚙️ Feature Engineering
- 🤖 Machine Learning Model Training
- 🎯 Hyperparameter Tuning
- 📉 Model Evaluation
- 💾 Model Saving

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Stock-Price-Prediction.git
```

Move into the project folder

```bash
cd Stock-Price-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the notebook

```bash
jupyter notebook
```
